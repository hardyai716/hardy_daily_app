## 修复：手机记账写入后显示 0
- 现象：手机新增支出后线上表出现「日期/金额为空」的行，页面统计为 0。
- 根因：import_csv 克隆出的新表把字段类型降级（date→text、currency→number、select→text），
  而页面 pushMoney/pushPlan/pushHabit/pushFitness/pushShopping/pushMedia 仍按源表类型写
  `{date}`/`{currency}`/`{select}` → 类型不匹配的值被丢弃，只有 text 字段（分类）写进去了。
- 修复：给页面加字段类型自适应层——启动时 db.getSchema 缓存 6 张表的 FIELD_TYPES/FIELD_OPTIONS，
  新增 `pv(dbId, field, value)` 按真实类型包装属性值，所有 push*/updateRemote* 改走 pv()。
  走 edit-flow：create_page_transaction → 改 → §5.3 写入回读验证（插 [TEST] 读回删除）→ commit v1 → 重新 publish。
- 遗留已清：用户确认后删除了 2 条空记录，收支表现存 52 行、无空值行。
- 经验：编辑托管页面时 python 读写 HTML 必须 io.open(..., newline="")，否则 CRLF 被统一成 LF，
  双向 diff 自检会出现全文件重写；多行替换串也要按 CRLF 规范化。
